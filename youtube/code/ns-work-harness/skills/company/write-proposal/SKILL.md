# Prepare a customer proposal

1. Establish the customer's goal using their company record when access is available, otherwise use the brief supplied by the employee. If neither is available, ask for the customer goal before drafting.
2. Draft four sections: Customer goal, Proposed scope, Assumptions, Next steps.
3. Connect the proposed scope to the confirmed need. Mark unconfirmed pricing, timelines and deliverables as requiring confirmation.
4. Cite record IDs when using company records. For employee-supplied facts, identify the source as the employee brief. Keep assumptions separate from confirmed facts.
5. Present the draft in chat for review. When the employee asks to save it and a writable workspace is available, write /work/proposal.md. Drafting is complete when the employee can inspect the requested output.
6. Sending is a separate step, only on the employee's request and through the application's review process. If sending is unavailable, leave the draft ready for review.
