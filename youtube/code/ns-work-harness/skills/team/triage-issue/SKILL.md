# Triage a technical issue

1. Retrieve matching records with issue_lookup. Cite the issue IDs.
2. Summarize the observed symptom and separate it from possible causes.
3. Recommend a bounded next check and identify the team responsible.
4. Present findings in chat and mark any unverified hypothesis explicitly. Save under /work/ only when requested and a writable workspace is available.
5. Finish with evidence, next check, owner and unresolved questions. Do not claim that a proposed fix has been executed.
